# Pizza Sales Analysis Using Python

## Project Overview

This project analyzes pizza store transaction data to identify sales trends, product performance, customer purchasing patterns, and opportunities for business improvement.

**Project Type:** Data Analytics Portfolio / Practice Project

## Tools and Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Business Objectives

- Evaluate total revenue, total orders and pizzas sold.
- Analyze sales trends by weekday, hour and month.
- Compare revenue contributions by pizza category and size.
- Identify the best-selling and least-selling pizzas.
- Examine frequently used ingredients.
- Calculate average order value and average pizzas per order.

## Key Performance Indicators

| KPI | Result |
|---|---:|
| Total Revenue | $817,860.05 |
| Total Pizzas Sold | 49,574 |
| Average Order Value | $38.31 |
| Average Pizzas per Order | 2.32 |

## Key Findings

- Thursday, Friday and Saturday showed strong order and revenue performance.
- The busiest periods were approximately 12–1 PM and 4–6 PM.
- July recorded a modest increase in monthly orders and revenue.
- Top-performing pizzas included Classic Deluxe, Barbecue Chicken and Thai Chicken.
- Lower-performing pizzas included Brie Carre, Spinach Supreme and Mediterranean.

## Business Recommendations

- Align staffing and ingredient availability with peak hours and busy weekdays.
- Review promotional opportunities for strong-selling pizza varieties.
- Investigate low-performing products before making menu changes.
- Monitor category and size demand to improve inventory planning.

## How to Run

1. Download or clone the repository.
2. Install the required libraries: `pip install pandas numpy matplotlib seaborn plotly jupyter`.
3. Open `Pizza Sales Analysis.ipynb` in Jupyter Notebook.
4. Ensure `pizza_sales.csv` is available at the path referenced by the notebook; adjust the CSV path if necessary.
5. Run the notebook cells in sequence.
